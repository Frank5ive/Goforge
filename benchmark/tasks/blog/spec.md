# Blog API

A service for authors and their posts. Data may be kept in memory.

## Author

| Field        | Type   | Rules                                                 |
|--------------|--------|-------------------------------------------------------|
| `id`         | string | Generated by the server, unique                       |
| `name`       | string | Required, not blank                                   |
| `email`      | string | Required; must contain exactly one `@` with text on both sides |
| `created_at` | string | RFC 3339 timestamp, set by the server when created    |
| `updated_at` | string | RFC 3339 timestamp, set by the server on every change |

## Post

| Field        | Type    | Rules                                                 |
|--------------|---------|-------------------------------------------------------|
| `id`         | string  | Generated by the server, unique                       |
| `author_id`  | string  | Required; must be the ID of an existing author        |
| `title`      | string  | Required, not blank                                   |
| `body`       | string  | Required, not blank                                   |
| `published`  | boolean | Defaults to `false` when omitted                      |
| `created_at` | string  | RFC 3339 timestamp, set by the server when created    |
| `updated_at` | string  | RFC 3339 timestamp, set by the server on every change |

## Endpoints

| Method and path              | Success                              | Errors              |
|------------------------------|--------------------------------------|---------------------|
| `POST /authors`              | `201` with the new author            | `400`, `422`        |
| `GET /authors`               | `200` with a page of authors         | `400`               |
| `GET /authors/{id}`          | `200` with the author                | `404`               |
| `PUT /authors/{id}`          | `200` with the author                | `400`, `404`, `422` |
| `DELETE /authors/{id}`       | `204` with no body                   | `404`, `409`        |
| `GET /authors/{id}/posts`    | `200` with a page of the author's posts | `400`, `404`     |
| `POST /posts`                | `201` with the new post              | `400`, `422`        |
| `GET /posts`                 | `200` with a page of posts           | `400`               |
| `GET /posts/{id}`            | `200` with the post                  | `404`               |
| `PUT /posts/{id}`            | `200` with the post                  | `400`, `404`, `422` |
| `DELETE /posts/{id}`         | `204` with no body                   | `404`               |
| `GET /health`                | `200`                                |                     |

- `POST` and `PUT` take every field except `id`, `created_at`, and `updated_at`. `PUT` replaces
  them all, so the same rules apply as for `POST`.
- A post whose `author_id` isn't an existing author is a `422`.
- Deleting an author who still has posts is a `409`; the author is kept.
- `GET /authors/{id}/posts` lists only that author's posts, and is a `404` when the author
  doesn't exist.

## Conventions

- Request and response bodies are JSON.
- Errors respond with a JSON body `{"error": "<message>"}` and the status code:
  `400` for a body that isn't valid JSON or an invalid query parameter, `404` when no item has
  the ID, `409` for the conflict described above, `422` when the data breaks a rule above.
- Lists: `GET /<items>?limit=<n>&offset=<n>` responds with
  `{"items": [...], "total": <number of matching items>, "limit": <limit used>, "offset": <offset used>}`,
  oldest first. `limit` defaults to 20 and larger values than 100 are treated as 100; `offset`
  defaults to 0. A negative or non-numeric `limit` or `offset` is a `400`.
